# PhotoSweet brand

The PhotoSweet mark (a six-blade aperture with a sparkle on a violet-to-rose gradient) and
wordmark, owned by salim-slimani.

- `photosweet-mark.svg`: the app mark alone.
- `photosweet-logo.svg`: mark + wordmark for light backgrounds.
- `photosweet-logo-white.svg`: mark + wordmark for dark backgrounds.

The app icon in `assets/app-icon/` is the same mark; regenerate both with
`packaging/gen_icons.py`. These files are licensed like the rest of PhotoSweet (MIT OR
Apache-2.0); see `LICENSE-brand.txt`.
