PhotoSweet portable mode

While this file sits next to photosweet.exe, PhotoSweet keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotoSweetData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move PhotoSweet with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photosweet) instead.
If PhotoSweetData can't be written (for example on a read-only drive), PhotoSweet says so and
uses %APPDATA%\Photosweet instead.
